# Газетний сканворд — Telegram Mini App

Звичайна статична гра (HTML + JS), як твої інші міні-аппи. Ні ПК, ні Python-бот, ні сервер не потрібні — усе робиться зі смартфона.

## Що в комплекті

| Файл | Навіщо |
|---|---|
| `index.html` | сама гра |
| `config.js` | налаштування (Firebase для Залу слави, версія) |
| `scanwords.json` | 10 випусків сканворду |
| `photos_list.txt` | список фото, які треба додати (ім'я файлу → хто на фото) |

## Крок 1. Залити на GitHub

1. Відкрий github.com у браузері телефона (за потреби — «Версія для ПК»).
2. Створи новий репозиторій, наприклад `scanword`, тип **Public**.
3. **Add file → Upload files** і вибери `index.html`, `config.js`, `scanwords.json`. Натисни **Commit changes**.
4. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)` → **Save**.
5. Через 1–2 хвилини сторінка буде тут: `https://ТВІЙ_ЛОГІН.github.io/scanword/`
   Відкрий це посилання в браузері: має з'явитися меню гри.

## Крок 2. Підключити до Telegram

1. У `@BotFather` створи бота (`/newbot`) або візьми наявного.
2. `/mybots` → твій бот → **Bot Settings → Menu Button → Configure menu button**.
3. Надішли посилання з кроку 1 (обов'язково `https://…`), потім назву кнопки, наприклад «Сканворд».
4. Відкрий бота в Telegram і натисни кнопку меню біля поля вводу — гра запуститься.

Є й другий варіант: `/newapp` у BotFather дає окреме посилання виду `t.me/бот/назва`.

## Фото («Хто на фото?»)

У кожному випуску по 2 фото-питання. Самих зображень у комплекті немає, бо це фото реальних людей. Без них гра працює: у клітинці просто значок 📷, а питання видно над клавіатурою.

1. Відкрий `photos_list.txt`: там написано, який файл кого показує (`p_001.jpg` — ПІТТ тощо).
2. Знайди фото (краще з вільною ліцензією, наприклад на Wikimedia Commons), обріж приблизно до квадрата, до 300×300 пікселів.
3. Завантаж у репозиторій через **Add file → Upload files** з точними іменами `p_001.jpg`, `p_002.jpg`… Можна класти просто в корінь поруч з `index.html`. Розширення `.jpg`, `.jpeg`, `.png` і `.webp` підходять, а папка `photos/` теж працює.

## Зал слави (необов'язково)

Без налаштувань Зал слави показує лише твої особисті рекорди. Щоб був спільний рейтинг, як в інших аппах:

1. У Firebase створи **Realtime Database** і скопіюй її адресу.
2. У вкладці **Rules** встав:
   ```json
   { "rules": { "scanword": { ".read": true, ".write": true } } }
   ```
3. У `config.js` встав адресу в `FIREBASE_DB_URL`.

## Оновлення

- Змінив `scanwords.json` або додав фото — завантаж файл з тим самим іменем (він замінить старий) і збільш `VERSION` у `config.js` (1 → 2), щоб Telegram не показував стару закешовану версію.
- Нові випуски: просто додай нові об'єкти в масив `scanwords.json`. Гра підхопить скільки завгодно випусків.

## Як влаштована гра

- Прогрес, час і рекорди зберігаються на пристрої автоматично.
- Очки: 1000 − 1 за кожні 3 секунди − 50 за підказку − 20 за перевірку з помилками (мінімум 100).
- Працює і у вертикальному, і в горизонтальному положенні телефона.
